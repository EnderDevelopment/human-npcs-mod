# Human NPCs Mod

Add realistic human-like NPCs to your Minecraft Bedrock world

## Features

- Adds human-like AI player NPCs to Minecraft Bedrock
- Supports natural spawning of NPCs
- Includes gear tiers and survival behaviors for NPCs
- Implements group dynamics for NPCs

## Requirements

- Minecraft Bedrock Edition 1.21.4
- Fabric Loader 0.14.0 or higher
- Java 17 or higher

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/human-npcs-mod/releases)
2. Place the mod file in your `mods` folder
3. Launch Minecraft Bedrock with Fabric Loader

## Usage

Once installed, NPCs will spawn naturally in your world. You can interact with them just like regular players.

## Configuration

The mod does not have a configuration file. All settings are hardcoded in the mod.
